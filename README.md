# 网页内容抓取器 · Web Clipper

一款轻量的 Chrome 扩展（Manifest V3），一键提取网页正文，支持**纯文本**与 **Markdown** 两种格式，并可一键转发到 Claude / ChatGPT / Gemini 进行总结、翻译或追问。

> 提取算法穿透 **iframe**、**Shadow DOM** 与 **slot**，兼容 wujie、micro-app 等微前端框架渲染的页面。

## ✨ 功能特性

- **智能提取 / 完整页面**：智能模式基于正文评分自动定位主内容区，过滤导航、广告、评论等噪音；完整模式抓取整页。
- **双格式输出**：纯文本或结构化 Markdown（保留标题、列表、表格、代码块、链接、图片等）。
- **穿透复杂 DOM**：深度遍历 Shadow DOM、slot 与多层 iframe，多框架结果自动合并去重。
- **批量抓取**：勾选当前窗口的多个标签页，一次性抓取并合并内容。
- **一键复制**：全文、选中内容、或「标题 + 链接」。
- **转发到 AI**：内置预设指令（总结要点、翻译成中文、基于内容提问、生成接口文档），直接打开对应 AI 站点并自动填入。
- **快捷键**：`Alt+Shift+C` 打开抓取面板。

## 📦 安装（开发者模式）

1. 下载或克隆本仓库到本地。
2. 打开 Chrome，访问 `chrome://extensions/`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择本项目文件夹。
5. 在任意普通网页点击工具栏图标，或按 `Alt+Shift+C` 即可使用。

## 🚀 使用方法

1. 在想要抓取的网页上打开扩展弹窗（默认自动提取当前页面内容）。
2. 切换 **纯文本 / Markdown** 格式，或在 **智能提取 / 完整页面** 之间选择。
3. 点击 **一键复制全文**，或选中页面部分内容后 **复制选中内容**。
4. 需要交给 AI 处理时，选择预设指令并点击 **Claude / ChatGPT / Gemini**，扩展会打开对应站点并自动填入内容。
5. 需要一次处理多个页面时，点击 **批量抓取**，勾选标签页后合并抓取。

## 🗂️ 项目结构

```
web-clipper/
├── manifest.json     # 扩展清单（MV3）：权限、快捷键、入口
├── background.js     # Service Worker：转发内容到 AI 站点并自动填入
├── popup.html        # 弹窗界面与样式
├── popup.js          # 提取逻辑：智能/完整提取、Markdown 转换、批量抓取、复制、转发
└── icons/            # 扩展图标
```

## 🔐 权限说明

| 权限 | 用途 |
| --- | --- |
| `activeTab` / `scripting` | 在当前页面注入提取脚本 |
| `tabs` | 批量抓取时读取标签页列表 |
| `clipboardWrite` | 复制内容到剪贴板 |
| `storage` | 保存「自动提取」等偏好设置 |
| `<all_urls>` | 允许在任意网页上提取内容 |

所有提取与处理均在本地浏览器内完成，扩展不会上传或收集任何页面数据。

## 🛠️ 技术说明

- **正文定位**：基于文本长度、链接密度、段落数量及类名/ID 语义的启发式评分。
- **Shadow DOM 穿透**：自行递归遍历 `shadowRoot` 与 `slot.assignedNodes()`，弥补 `innerText` / `textContent` 无法读取 Shadow Root 的限制。
- **覆盖率回退**：当智能选中的容器文本量不足整页一半时，自动回退到整页提取（兼容微前端把正文渲染进 Shadow Root 的场景）。
- **AI 填入**：短内容走 URL 参数预填；长内容或 Gemini 则注入脚本写入输入框，失败时内容已在剪贴板可手动粘贴。
